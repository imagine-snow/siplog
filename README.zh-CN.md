# 酒迹 SipLog

[English](README.md) · 中文

酒迹是一款本地优先的轻量饮酒记录工具，像记账一样记录喝了什么、喝了多少、瓶中还剩多少，以及长期花费与变化。

酒迹旨在帮助用户记录饮酒情况，并通过可视化更直观地了解自己的饮酒习惯。本应用不鼓励饮酒，也不鼓励增加饮酒量。

本仓库保存 **v0.5.3 首次朋友内测版**，包含源码、测试、文档和可离线使用的酒款库快照，不包含个人饮酒记录或本地测试备份。

[打开网页版](https://jiuji-drink-log.imagine-snow.chatgpt.site/) · [更新记录](CHANGELOG.md) · [数据来源](DATA_SOURCES.md)

## 功能

- 分步录入：选择酒款 → 确认度数与容量 → 记录饮用量 → 分配个人份额。
- 啤酒、苹果酒按瓶/罐计数；烈酒和葡萄酒默认拖动剩余液面估算。朋友喝掉的部分减少库存，但不计入个人摄入。
- 电子酒柜在饮优先，历史默认折叠，支持收藏与可选本地封面。
- 明细列表、历史记录编辑、日历热力图，以及饮用量和花费统计。
- 中英文界面、常见品牌中文别名；找不到酒款可以自行添加。
- JSON 备份导出与恢复。清空记录、酒柜、收藏和照片必须经过两次独立确认，已下载的备份文件保留。
- 支持添加到主屏幕和本地运行版；不要求情绪、评价或未饮酒打卡。

## 本地运行

推荐使用 **Node.js 24**，包管理器使用 `package.json` 中固定的 **pnpm 11.25.0**；声明的最低 Node 版本为 22.13。

```bash
pnpm install --frozen-lockfile
pnpm dev
```

在浏览器打开终端打印的地址。

独立静态构建不需要账号、后端或 API 密钥：

```bash
pnpm build:download
node download/start.cjs
```

打开 `http://localhost:4173` 并保持终端运行。Windows 安装 Node.js 后，也可双击 `download/Start-Windows.cmd`。请不要直接打开 `index.html`。

`download/` 内的文件可以部署到 HTTPS 网站根目录。部署到子目录需要调整资源、manifest 和 service worker 路径。本版不是 EXE 或 APK 安装程序。

## 数据库与参考来源

个人数据存储与酒款资料来源是两个不同部分：

| 数据 | 来源 / 存储 | 用途 |
| --- | --- | --- |
| 个人记录、酒柜和照片 | 浏览器 **IndexedDB**（`jiuji-ledger`） | 保存在当前浏览器，没有云端数据库或自动同步 |
| 30,152 条商品规格 | [Open Food Facts](https://world.openfoodfacts.org/) / [官方导出](https://huggingface.co/datasets/openfoodfacts/product-database) | 名称、品牌、分类，以及已有的度数和容量 |
| 5,801 条啤酒条目 | [Open Beer Database](https://openbeerdb.com/) | 历史啤酒、酒厂、风格与度数资料 |
| 11 条规格补充 | [DATA_SOURCES.md](DATA_SOURCES.md) 中列出的品牌官网 | 少量酒瓶标签上的事实规格 |

合计 **35,964 条商品规格条目**，导入日期为 **2026-10-26**。Open Beer Database 使用 **2011-12-14 历史快照**，不代表当前在售情况。同款酒的不同容量或地区版本可能分别计数；缺失的度数由用户按瓶身补充。中文别名由本项目维护，并非数据库提供的官方翻译。

合并酒款库遵循 **ODbL-1.0**，适用内容保留 **DbCL-1.0** 声明。每条数据的来源链接与标识保存在 `public/data/drinks.json`，许可副本位于 `public/data/`。完整来源、快照版本及导入方式见 [DATA_SOURCES.md](DATA_SOURCES.md)，许可说明见 [NOTICE.md](NOTICE.md)。

## 数据与隐私

- 记录保存在当前浏览器的 IndexedDB。清除浏览器数据可能导致记录丢失，更换浏览器、设备或网址前请导出备份。
- 网页版与本地运行版分别存储数据，可通过备份导出与恢复迁移。
- 酒款搜索与照片处理在本地完成。应用没有自行加入行为分析，也不把饮酒记录存入云端；托管服务本身可能保留访问日志或流量指标。
- 未保存的草稿仅在内存中保留。切换币种只更改符号，不进行汇率换算。
- 液面与纯酒精量均为估算，本版不提供医疗建议。

## 计算口径

- 瓶内减少量 = 容量 ×（上次余量百分比 − 本次余量百分比）÷ 100。
- 个人饮用量 = 瓶内减少量 × 本人份额。
- 纯酒精估算克数 = 个人毫升数 × 酒精度 ÷ 100 × 0.789。
- 一次保存计一次饮酒，只有朋友饮用或库存调整不计个人饮酒次数。
- 未填价格不等于零；整瓶购入支出和分摊的饮用成本分别展示。
- 日历空白只代表没有记录，不能推断当天没喝酒。


## 后续可能开发的功能

以下内容仍在考虑中，当前内测版尚未提供，具体范围与时间可能调整。

- **可选的健康提醒：** 参考已发表研究与公共卫生指南，并明确列出文献来源。当用户前一天记录的酒精摄入量较高时，给出适当、温和的提醒。提醒标准会在实现前审查，用户可以关闭提醒；功能用于帮助了解自己的饮酒情况，不用于诊断，也不将某个饮酒量定义为完全无风险。
- **可选的社区功能：** 提供独立空间，供用户自愿分享体验、心情、场合和照片。上线前会考虑隐私与内容管理；日常饮酒记录仍保持简单，不依赖社区功能。
